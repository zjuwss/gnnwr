# KNN Systematic Benchmark Results

## Experiment Configuration

### Data Generation

| Parameter | Value |
|-----------|-------|
| Generator | `generate_spatial_data(n_samples=N, seed=42)` |
| Spatial range | lng ∈ [100, 125], lat ∈ [20, 45] |
| X variables | elevation, temperature, precipitation, ndvi, population, industry |
| Y variable | pm25 (simulated spatial non-stationarity) |
| Spatial non-stationarity | 4-zone coefficients (NE/NW/SE/SW) with tanh transitions |
| Noise | σ = 5, y clipped to [5, 500] |

### Dataset Split

| Parameter | Value |
|-----------|-------|
| test_ratio | 0.2 |
| valid_ratio | 0.1 |
| sample_seed | 42 |
| process_fn | minmax_scale |
| Reference | train set only (default when Reference=None) |

| N | Train | Valid | Test | Reference (=Train) |
|---|-------|-------|------|---------------------|
|   1,000 |   720 |    80 |  200 |                 720 |
|   5,000 |  3600 |   400 | 1000 |                3600 |
|  10,000 |  7200 |   800 | 2000 |                7200 |
|  50,000 | 36000 |  4000 | 10000 |               36000 |
| 100,000 | 72000 |  8000 | 20000 |               72000 |

### Training Hyperparameters

| Parameter | Value |
|-----------|-------|
| Epochs | 50 |
| Optimizer | Adam |
| Learning rate | 0.01 |
| Weight decay | 0.0001 |
| LR scheduler | StepLR (default in GNNWR) |
| Dropout | 0.2 (default) |
| Batch norm | True (default) |
| Activation | PReLU(init=0.4) (default) |
| OLS init | True (output layer fixed to OLS coefficients) |
| Batch size | N=1000: 128, N=5000: 256, N=10000: 256, N=50000: 512, N=100000: 1024 |
| SWNN layers | auto: `default_dense_layer(input_dim, n_coef)` |
| Early stopping | disabled |
